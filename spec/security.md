# 安全与密钥

参考：[OWASP ASVS / Secrets 常识](https://owasp.org/www-project-application-security-verification-standard/)、Twelve-Factor Config

## 密钥与敏感信息

- 密码、Token、私钥、证书等禁止写入源码与提交历史。
- 使用 `.env`（加入 `.gitignore`）或系统 / 密钥管理注入；提供 `.env.example`（仅占位符）。
- 日志、截图、交接文档中脱敏；勿把真实密钥贴进聊天或 issue。

## 依赖与供应链

- 锁定依赖版本；升级时关注漏洞公告。
- 不随意执行不明来源脚本；安装来源限于官方或项目可信镜像。

## 权限与操作

- 最小权限：进程、文件、设备端口、远端账号均按需授权。
- 写操作、删除、固件 / 参数下发、生产库变更等高风险动作：先评估与用户确认，并记操作日志。
- 默认不对外暴露调试端口与管理接口；如需暴露，加认证与网络隔离说明。

## 配置与默认值

- 安全相关默认偏保守（超时、重试上限、鉴权开启）。
- 区分「可公开配置」与「机密配置」；机密只走环境 / 密钥通道。
